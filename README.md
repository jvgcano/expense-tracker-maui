# Expense Tracker MAUI

A cross-platform expense tracking application built with .NET MAUI.

## Goals

- Learn and apply modern .NET MAUI practices.
- Follow MVVM and Clean Architecture principles pragmatically.
- Keep the codebase simple, scalable, and maintainable.
- Build in public through meaningful Git history.

## Planned Features

- Expense & income tracking
- Categories
- Budgets
- Dashboard
- Reports
- Recurring transactions
- Data backup & restore
